**[hugozh](https://github.com/hencter/hugozh)** · [hugozh.cn](https://hugozh.cn/)

**[mimenote](https://github.com/hencter/mimenote)**
本地优先、可高度自定义的 Markdown 知识库桌面应用，Rust + Tauri 实现。
<sub>*A local-first, highly customizable Markdown knowledge base for the desktop, built with Rust + Tauri.*</sub>

**[monopoly-3d-ai](https://github.com/hencter/monopoly-3d-ai)** · [⭐ 2](https://github.com/hencter/monopoly-3d-ai/stargazers)

<sub>*A 3D Monopoly in the browser — AI opponents, card play, and online matches for up to 34 players.*</sub>

**[paiban](https://github.com/hencter/paiban)** · [在线试用](https://paiban-decide-now.app.workbuddy.host/)

<sub>*A no-friction decision tool: nothing but pairwise choices until the answer is obvious.*</sub>

**[tongtop-store](https://github.com/hencter/tongtop-store)**
TongTop Store：基于 Tauri 的桌面应用商店，含 Winget 分发包。
<sub>*A Tauri-based desktop app store, shipped with Winget manifests.*</sub>
